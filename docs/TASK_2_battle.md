依頼1（キャラ10体と図鑑）が終わっている前提。
対戦の計算はすでに完成していて、`js/battle.js` に入っている。**Codexは計算を作らず、画面を作ってこのファイルを使う**。

| ファイル | 中身 |

## 1. 読み込み

`index.html` の読み込み順に `js/battle.js` を加える。

```
data/characters.js → data/rules.js → js/battle.js → js/game.js
```

`js/battle.js` は `data/characters.js` のキャラ（`id, name, grade, resolve, tags, stats`）をそのまま使う。

## 2. 使い方（battle.js の入口）

```js
const res = runBattle({
  a: { ch: CHARACTER（自分の個体のキャラ）, ind: 自分の個体（power, speed, wisdom を使う） },
  b: { ch: 相手のキャラ, ind: 相手の個体 },
  stage: { name: '古戦場', features: ['戦場', '開けた場所'] },   // 省略可
  seed: 数値                                                      // 省略するとランダム
});
// res.winner … 0 / 1 / null　 res.log … 実況　 res.A / res.B … { name, hp, maxHp }　 res.rounds　 res.reason
```

- `res.log` の各行は `{ round, kind, text, side, dmg, hpA, hpB, note }`。`kind` は `stage / round / talk / info / skill / big / hit / miss / event`
- ゲームのルールは `GameServer` に集める決まりなので、`GameServer` に `practiceBattle(uid, enemyCharId, stage, enemyInd)` のような入口を作り、その中で `runBattle` を呼ぶ（将来サーバーへ移すため）

## 3. 画面：冒険タブに「対戦（練習試合）」を追加

`docs/battle-prototype.html` の見た目と動きを、ゲームの画面として作る。違いは次の3点だけ。

| 試作 | ゲーム |
|---|---|
| 両方のキャラを自由に選ぶ | **自分側は保管庫の個体から選ぶ**（キャラで絞り込み、個体値と称号が見える一覧から1体） |
| 個体値はランダム | 自分側は**選んだ個体の値**。相手側はランダムに生成し、「相手を引き直す」で変えられる |
| 画像は試作用 | ゲームの `imagePath()`（`img/` の画像）を使う |

### 画面の決まり（試作と同じ）
- **1画面に収める**：上に2体（全身が切れずに入る大きな絵・等級・覚悟・個体値・HPバー）、中央に実況、下にボタン。実況の欄だけが中でスクロールする
- **舞台**：試作の10種類の舞台と、17個の特徴を自分で組み合わせる小窓（特徴の説明は `STAGE_FEATURES` にある）
- **実況**：普通の攻撃（`hit` / `miss`）が続くラウンドは「ラウンド5〜8：打ち合いが続く（Aが○、Bが○ダメージ）」のようにまとめ、`skill`・`big`・`talk`・`info` はそのまま表示。試作の `compress()` を参考にする
- **ボタン**：個体を選ぶ／相手を引き直す／実況の速さ（ふつう・はやい）／結果まで飛ばす／戦わせる
- **「戦わせる」はいつでも押せる**。実況の途中で押すと、今の実況をやめて新しい戦いを始める。実況中は「やり直す」、終わったら「もう一度」と表示する
- 結果（勝者・理由・ラウンド数）は実況の一番下に出す
- 高さ600〜932px、幅360〜430pxで、スクロールなしに収まること

### 報酬
練習試合には**報酬を付けない**（クエストは依頼3で作る）。

## 4. 図鑑とのつながり（小さな追加）
図鑑の「戦闘能力」タブの一番下に「このキャラと練習試合をする」ボタンを置き、押すと対戦画面が**相手＝そのキャラ**の状態で開く。

## 5. 完了の条件

1. 冒険タブから対戦画面が開き、保管庫の個体を選んで、10体のどの相手とも戦える
2. 試作と同じく、1画面に収まり、実況だけがスクロールする。キャラの全身が切れない
3. 「戦わせる」がいつでも押せて、途中で押すと新しい戦いが始まる
4. 実況のまとめ表示、結果まで飛ばす、速さの切り替えが動く
5. 舞台の選択と特徴の組み合わせが動き、結果に反映される
6. `node tools/battle-sim.js` が動き、**ラウンド数の中央が30〜50**、全体の勝率が表示される
7. `node --check js/game.js` と `node --check js/battle.js` が通る
8. 既存の保存データで開いてもエラーが出ない
