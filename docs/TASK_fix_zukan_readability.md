# 依頼：図鑑のキャラページを読みやすくする（絵が切れる・文章が読みにくい）

図鑑でキャラを開いたときのページ（基本／物語／戦闘能力／記録のタブ）に、次の問題がある。
ゲームのルールやデータには触らず、**見た目だけ**を直すこと。

## 起きていること（実機：幅375px・高さ667px前後のiPhone）

1. **キャラの絵の下の端（足元）が切れている**。絵の枠の下が、タブの帯に隠れている
2. **文章を読む場所が狭い**。絵が画面の上半分を占めたまま固定されているので、文章は画面の下3分の1ほどしか使えない
3. **タブの「戦闘能力」が2行に折り返して**、タブの帯が高くなっている
4. ページが画面の端から少し内側に浮いた箱（ダイアログ）になっていて、横幅も狭い

## 直し方

### A. ページを画面いっぱいにする
- キャラページは、浮いた箱ではなく**画面全体を使う表示**にする（左右の余白は12px程度）
- 閉じるボタン（×）は右上に残す

### B. 絵は「最初は大きく、読むときは小さく」
- 開いた直後は、今と同じく絵を大きく見せる（画面の高さの35〜40%）
- **下の中身をスクロールし始めたら、絵の部分が縮んで**、最後は「小さな絵（48px程度）＋名前＋等級」の1行の帯になる
- 縮んだ帯とタブは画面の上に固定し、その下の広い範囲で文章を読めるようにする
- 一番上までスクロールを戻すと、絵がまた大きくなる
- 絵は**どの大きさのときも全身が入る**ようにする（`object-fit: contain`、足元が枠やタブに重ならないよう、絵の枠の下に余白を取る）

### C. タブを1行に収める
- 4つのタブは**同じ幅**で横に並べ、文字は折り返さない（`white-space: nowrap`）
- 幅が足りないときは文字を少し小さくする（最小13px）

### D. 文章を読みやすくする
- 本文の文字は**16px**、行間は**1.9**程度
- 段落（1行ごと）の間に少し余白を取る
- 見出し（「夢岩・墜星」などのまとまりの名前）は本文より大きく太くし、上に余白を取る
- 文章のカードの左右の余白を広げ、背景と文字の色の差をはっきりさせる（薄い灰色の文字を使わない）
- 「↓」だけの行は、中央寄せで少し小さく表示する（流れを示す記号として読みやすく）
- 「」で始まり」で終わる1行のセリフは、今の物語タブと同じく、薄い背景で区別する

### E. 戦闘能力タブの並び
- 戦闘タイプ → 能力値の棒グラフ → 覚悟・性質タグ → 文章のまとまり、の順は今のまま
- 能力値の棒グラフは、文章を読む邪魔にならないよう、上下の余白を少し詰める

## 完了の条件

1. 幅360・375・390・430px、高さ600・667・844pxのどれでも、**開いた直後にキャラの全身が切れずに見える**
2. 文章をスクロールすると絵が縮み、**画面の7割以上を文章に使える**
3. 4つのタブが**1行**に収まっている
4. 本文が16px以上で、行間が広く、長い文章でも読みやすい
5. 10体すべてで崩れない（縦長のマデランデス、横に広いヴァルガルドやバサラで特に確認）
6. 物語タブの「続きを読む」「すべて開く」の動きは今のまま
7. `node --check js/game.js` が通る

## 変えてほしくないもの

- `stories/` と `combat/` の文章
- データ（`data/`）とゲームのルール
- 図鑑の一覧（グリッド）の見た目

## 確認のしかた

作者がスマホで、No.003 マデランデス（縦長の絵・文章が長い）と No.001 ヴァルガルド（横に広い絵）の「戦闘能力」タブを開き、
開いた直後に全身が見えること、スクロールすると絵が縮んで文章が広く読めることを確かめる。
