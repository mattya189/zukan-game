# 仕様（2026年9月時点）

## 全体の流れ

ガチャで個体を引く → 図鑑にスタンプと情報が開放される → 個体を厳選し、送り出してコインにする → コインでまたガチャ。
これに加えて、ログインボーナス・ミッション・探索・クエスト（カードバトル）がコインの入り口になっている。

## ガチャ

- 1回100コイン／10回1000コイン（10回では★3以上が1体確定）
- レアリティ：★1 50%／★2 28%／★3 15%／★4 5.5%／★5 1.5%
- 特異個体：0.5%（見た目が変わり、送り出すとコイン5倍）
- 初期コイン3000、保管庫の上限200体

## 個体値（10項目）

レアリティとは無関係。大きい値ほど急激に出にくい（`data/rules.js` の `POWER_RULE` / `RATIO_RULE`）。

| 種類 | 項目 | 決まり方 |
|---|---|---|
| 上に伸びる | パワー、すばやさ、かしこさ、うんのよさ、かがやき、性格の強さ | 出発点 × 10^d。上限9,999,999。出発点の10倍で約1/50、100倍で約1/1万 |
| 両方向に伸びる | 体重、身長、食欲 | 基準 × 倍率。1.5倍/3分の2で約1/37、3倍/3分の1で約1/7,400、上限100倍 |
| 固定 | 出会い番号 | そのキャラが世界で何番目に生まれたか |

- 総合値＝主要5項目の「桁」の合計×100（どれか1つが桁違いでも、他の項目の差が効く）
- 称号16種類（`TITLES`）。おおむね1/35〜1/1万で付く。称号はバトルで攻撃・体力・速さのどれかに+1

## 図鑑

- キャラ×レアリティのスタンプ。★1分類／★2以降は `stories/` の文章が開放
- ★3で型、★4で縁、★5で奥義がバトルで使えるようになる
- 初スタンプ報酬（★1:50〜★5:1000）、1キャラ全★で1500
- 世界記録：仮プレイヤー（NPC）と自分の記録。個体を送り出しても残る

## コインの入り口

| 手段 | 内容 |
|---|---|
| ログインボーナス | 毎日300、7日目1000 |
| ミッション | 5種類（ガチャ10回、送り出し5体、探索2回、個体票3回、クエスト1勝）＋全部達成で300 |
| 探索 | 5分／1時間／8時間。パワーとかしこさで報酬増、すばやさで短縮、うんのよさで大成功2倍 |
| クエスト | 初回クリア500〜3000、以降は1日5回まで150〜800 |
| 送り出し | ★1:10〜★5:500（特異個体は5倍） |

## バトル

自動で進むカードゲーム。プレイヤーはデッキ・リーダー・作戦・号令を決める。

- デッキ8〜20枚（キャラ5枚以上、属性3種まで、アーティファクト5枚まで）
- リーダー体力70（土のリーダーは+22）、初期手札4枚、毎ターン エナジー＝ターン数（最大10）
- 盤面は3列×前後2段。前列は正面と戦い、後列は射程・飛行があれば攻撃できる
- 1戦はおおよそ10〜15ターン。20ターンで残り体力判定。山札切れは1回2ダメージ
- 号令は1戦2回（総攻撃／守りの陣）、次のターンに効果
- カードの攻撃・体力は、コストとキーワード・固有能力の点数から自動計算（`compileCard`）
- 固有能力は「きっかけ×条件×効果」の部品で作る（`TRIGGERS` / `KEYWORDS` / 効果の種類）
- アーティファクトは場に出ない。発動型（即時）と設置型（同時2つまで）

## 保存データ

`localStorage['gachaZukanDemo_v2']`。プレイヤー情報、所持個体、図鑑、称号、探索、デッキ、自分の世界記録のみ。
仮プレイヤー（NPC）の世界は毎回その場で作り直す（キャラ数×40体）。

## いまの調整状況（tools/sim.js の結果）

- ランダム対戦：平均12ターン前後、先攻の勝率ほぼ50%
- 属性の勝率：風と光がやや高め（55%前後）、土と闇がやや低め（44%前後）
- クエスト：Lv2・Lv3が想定より簡単（目安は Lv2=5〜6割、Lv3=4〜5割）
