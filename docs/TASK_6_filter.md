# 依頼6：キャラを選ぶ画面に「戦い方」の絞り込みを付ける

クエスト・練習試合・集団戦の編成で個体を選ぶとき、**戦い方で絞り込めるようにする**。
新しいデータは要らない。すでに `data/characters.js` にある `tags`（性質タグ）・`resolve`（覚悟）・`grade`（等級）を使う。

## 1. 付ける場所

同じ絞り込みの部品を、次の画面すべてで使う。

- クエストの挑戦前（キャラ別の試練・周回）
- 練習試合（1対1・2対2・3対3）
- 集団戦クエストの編成
- 保管庫（ここにも付けると、厳選のときに便利）

## 2. 絞り込みの中身

今ある並び替えやキャラの絞り込みに加えて、次を足す。

| 分類 | 選べるもの | 元になるデータ |
|---|---|---|
| 距離 | 近接／遠距離／飛行 | `tags` |
| 型 | 長期戦／短期決戦／分析／高揚／自信 | `tags` |
| 役割 | 拘束／精神干渉／領域／音／大型／かわいい好き | `tags` |
| 覚悟 | 低い／ふつう／高い | `resolve` |
| 等級 | F／E／D／C／B／A／S | `grade` |

### 決まり
- **複数選べる**。同じ分類の中で2つ以上選んだときは「どれかに当てはまる」（例：近接＋遠距離＝どちらかを含む）
- **別の分類をまたいだときは「すべてに当てはまる」**（例：近接 かつ 短期決戦）
- 選んだ条件は、押すと外せる。「すべて解除」のボタンも置く
- 絞り込んだ結果が0体のときは「条件に合う個体がいません」と出し、解除を促す
- 絞り込んだ状態の件数を出す（例：「12体／48体」）
- 一度選んだ条件は、その画面を閉じるまで覚えておく（画面を開き直したら解除でよい）

### 表示
- 場所を取らないよう、**「絞り込み」ボタンで開く小窓**にする。選択中の条件は、ボタンの横に短く出す（例：「絞り込み：近接・短期決戦」）
- 小窓の中は、分類ごとに見出しを付けて、丸いボタン（チップ）を並べる形
- キャラ名・並び替え（今あるもの）はそのまま残す

## 3. ヒントとのつながり

クエストの挑戦前には「攻略のヒント」が出ている（例：「準備の時間を与えない、速い近接型の短期決戦が天敵」）。
このヒントの下に、**ヒントに合う条件をすぐ選べるボタン**を置く。

- ステージごとに、`STAGE_HINTS` の文章に合う条件を1〜2個決めておく（下の表）
- ボタンを押すと、その条件で絞り込まれる

| ボス | おすすめの絞り込み |
|---|---|
| ヴァルガルド（chr_001） | 短期決戦／遠距離 |
| バースクライ（chr_002） | 覚悟：高い |
| マデランデス（chr_003） | 短期決戦／近接 |
| タルンルソルク（chr_004） | 飛行／遠距離 |
| ダラガルド（chr_005） | 遠距離／分析 |
| カンタレイア（chr_006） | 近接／高揚 |
| アストラ＝プレア（chr_007） | 短期決戦／近接 |
| バサラ（chr_008） | 短期決戦／音 |
| トツカイザー（chr_009） | 長期戦／大型 |
| デウマグナ（chr_010） | 精神干渉／分析 |

この対応は `data/stages.js` ではなく、**新しく `STAGE_RECOMMEND` のような表を作って `js/game.js` 側に置く**（ステージのデータは変えない）。周回ステージには付けない。

## 4. 完了の条件

1. クエストの挑戦前・練習試合・集団戦の編成・保管庫で、同じ絞り込みが使える
2. 同じ分類は「どれか」、別の分類は「すべて」で絞り込まれる
3. 件数の表示、すべて解除、0体のときの案内が出る
4. 挑戦前のヒントの下のボタンを押すと、その条件で絞り込まれる
5. 幅360〜430pxのスマホ縦画面で崩れない。絞り込みの小窓が画面からはみ出さない
6. `node --check js/game.js` が通る
7. 既存の保存データで開いてもエラーが出ない

## 5. 変えてほしくないもの

- `data/characters.js`・`data/stages.js`・`data/team-stages.js`・`js/battle.js`・`js/team.js`
- 今ある並び替えとキャラ名の絞り込み（残したうえで、戦い方の絞り込みを足す）
