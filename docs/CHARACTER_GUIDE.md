# キャラを追加する手順

## 1. 用意するもの

| もの | 決まり |
|---|---|
| 画像 | 背景が透明なPNGから作った webp。大＝長辺512px、小＝長辺160px。全身が入り、周りに少し余白 |
| 名前・分類・種族 | 種族は2つまで |
| 図鑑の文章 | ★1〜★5。各★に「題」と本文 |
| 戦い方のイメージ | 例「崩れ落ちて押し潰す」「仲間を増やす」 |

## 2. ファイルの置き場所

```
img/chr_031_base_1.webp     通常（512px）
img/chr_031_base_1_s.webp   通常（160px）
img/chr_031_r4_1.webp       ★4（あれば）
img/chr_031_r5_1.webp       ★5（あれば）
stories/chr_031.js          図鑑の文章
data/characters.js          キャラ一覧に1ブロック追加
```

## 3. 個体値の傾向の決め方

| 項目 | 目安 |
|---|---|
| base_weight / base_height | 実際にありそうな重さ・大きさ。ここから多い方にも少ない方にも伸びる |
| speed_bias / wisdom_bias / luck_bias | 250〜850。÷5が出発点になる |
| appetite_bias | 200〜950。食いしん坊なら高く |
| likely_natures | 性格2〜3個。60%の確率でここから選ばれる |

## 4. バトルの部品の決め方

- **属性**：戦い方の方向性（火＝攻撃、水＝回復・妨害、風＝速さ、土＝守り、光＝強化、闇＝毒・一発）
- **コスト**：1〜8。攻撃と体力は「コスト×2+3」からキーワードと固有能力の点数を引いて自動計算される
- **ratio**：攻撃寄りの度合い（0.2＝守り型、0.65＝攻撃型）
- **キーワード**：0〜2個（`data/rules.js` の `KEYWORDS`）
- **固有能力**：きっかけ（登場時・倒れた時など）×条件×効果の組み合わせ。文章は自動生成される

同じ種族が3体以上になったら、種族をまとめる能力（「味方の○○が2体以上なら」）を持つキャラを1体入れると、デッキ作りが面白くなる。

## 5. 追加後の確認

```bash
node tools/sim.js battles 4000
```

- 新しいカードの勝率が46〜54%なら、そのままでよい
- 56%以上なら、コストを上げるか能力を弱める
- 44%以下なら、コストを下げるか能力を強める

## 6. 気をつけること

- **id は変えない・消さない**：保存データとつながっている
- **縁を作るなら**：`data/characters.js` 末尾の `BONDS` に2体の id を書く
- **クエストの敵に入れるなら**：`data/quests.js` の敵デッキに id を足す
- **画像を差し替えるとき**：版番号を上げた新しいファイル名にして、`art` の数字を上げる
