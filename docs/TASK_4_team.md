## 2. 集団戦の決まり（js/team.js に実装済み。画面の説明に使う）

- 2対2または3対3。**同じキャラを同じチームに入れることはできない**（`runTeamBattle` は同じキャラがいるとエラーにする。画面側で先に防ぐ）
- 各キャラは**前衛か後衛**に置く。前衛は狙われやすく、後衛は前衛が立っている間は狙われにくい
- 近接型は前衛で、遠距離型は後衛で力を出しやすい（近接型を後衛に置くと威力が落ちる。飛行型は落ちない）
- 前衛が0人でもよい（その場合は後衛が狙われる）
- 相手チーム全員を倒したら勝ち。60ラウンドで決着しなければ、残り体力の合計の割合で判定

### 使い方

```js
const res = runTeamBattle({
  teams: [
    [{ ch, ind, row: 'front' }, { ch, ind, row: 'back' }],      // 自分のチーム（保管庫の個体）
    [{ ch, ind, row: 'front' }, { ch, ind, row: 'back' }]       // 相手のチーム
  ],
  stage: { name, features: [...st.features], events: st.events, enemyState: st.enemyState, enemyPower: TEAM_STAGE_POWER[st.id] }
});
// res.winner（0 / 1 / null）、res.rounds、res.reason
// res.fighters … [{ side, id, name, row, hp, maxHp }]（自分のチームが先、相手のチームが後。teams に渡した順）
// res.log      … 実況。各行の hp は res.fighters と同じ順の体力の配列
// res.state    … 挑戦目標の判定用
```

`GameServer` に `teamPracticeBattle(uids, rows, enemyTeam)` と `teamQuestBattle(stageId, uids, rows)` のような入口を作り、その中で `runTeamBattle` を呼ぶ。

## 3. 編成の画面（保管庫から選ぶ）

- 2対2なら2体、3対3なら3体を、**保管庫の個体から**選ぶ（キャラで絞り込み、個体値と称号が見える一覧。依頼2の部品を使う）
- **同じキャラの個体を2体以上選ぼうとしたら、選べないようにして理由を表示する**
- 選んだ個体ごとに「前衛／後衛」を切り替えるボタン。最初は、近接型なら前衛、遠距離型なら後衛にしておく
- 最後に使った編成を保存し、次回はそれを初期状態にする（2対2用と3対3用を別々に）

## 4. 戦場の画面（docs/team-prototype.html と同じ）

### 並び
画面上部に、横一列で **「味方後衛｜味方前衛｜敵前衛｜敵後衛」** の4列を並べる。
- 左2列は青、右2列は赤の見出し。**味方と敵の境目に縦の点線**
- 同じ列に2体なら縦に2段。**3体なら列を広げ、上に2体・下に1体**の並びにする
- 列の幅は人数で変える：0人＝0.5、1人＝1、2人＝1.1、3人＝1.8（fr）。点線は境目に合わせて動かす
- 誰もいない列は細い点線の枠で、見出しは「後衛」「前衛」だけ
- 各キャラの枠：**全身が切れずに入る絵**、名前、HPバー。倒れたら灰色にする
- 絵は一覧用の小さい画像（`_s.webp`）でよい

### 実況
- 1対1と同じまとめ方（普通の攻撃が続くラウンドは「ラウンド5〜8：乱戦が続く（自分のチームが○、相手のチームが○ダメージ）」）
- 実況の文字は **16px・行間1.75**
- **戦っている間は、戦場の高さを低くし、ステージを選ぶ欄をしまって、実況を広くする**（高さ667pxの画面で実況が約350px）
- 右上の「実況を広く／絵を大きく」ボタンで、いつでも切り替えられる。ステージを選び直すと、絵が大きい表示に戻る

### ボタンと結果
- 依頼2と同じ（個体を選び直す／実況の速さ／結果まで飛ばす／戦わせる。「戦わせる」はいつでも押せて、途中で押すと新しい戦いになる）
- 結果の欄：勝利／敗北、理由、ラウンド数、報酬、挑戦目標（白い枠に濃い文字、「達成！」は緑、「未達成」は赤）
- 1画面に収まり、実況だけがスクロールすること

### 1対1の画面にも入れる
「実況を広く／絵を大きく」の切り替えと、戦っている間に実況を広げる動きを、**依頼2・3の1対1の対戦画面にも同じように入れる**。

## 5. 練習試合
依頼2の「対戦（練習試合）」に、**1対1／2対2／3対3** の切り替えを加える。
2対2・3対3では、相手のチームも自由に組める（キャラと前衛・後衛を選ぶ。個体値はランダム、「相手を引き直す」で変わる）。報酬なし。

## 6. 集団戦クエスト（data/team-stages.js）

| 名前 | 中身 |
|---|---|
| `TEAM_STAGES` | 10個。`id`（t001〜t010）、`boss`、`size`（2か3）、`name`、`story`（短い物語）、`features`、`enemies`（`{ id, row }`）、`enemyText`、`eventText`、`events`、`enemyState(ctx, 敵チーム, 自分のチーム)`、`goal: { text, check(res) }` |
| `TEAM_ENEMY_IND` | 相手の個体値（全員同じ） |
| `TEAM_STAGE_POWER` | クエストごとの敵の強さ（`enemyPower` に渡す） |
| `TEAM_REWARDS` | `{ first: 3000, repeat: 150, goal: 1000 }` |

- **そのボスのキャラ別の試練の段階3をクリアすると開く**（例：t001 はヴァルガルドの段階3クリアで開く）
- 報酬：初回3000、2回目以降150、挑戦目標の初達成で+1000
- クエスト一覧のキャラのカードに、4つ目の印として「集団戦」の状態（未解放／挑戦可／クリア／目標達成）を足す
- 挑戦前の画面に、物語（`story`）・相手チーム（絵・名前・前衛/後衛）・舞台の特徴・敵の状態・出来事・挑戦目標・報酬を出す
- 保存データの `questProgress` に `teamCleared`・`teamGoals` を足す（古い保存データには空の形で補う）
- ミッション「クエストか周回で1回勝つ」に、集団戦クエストの勝利も数える
