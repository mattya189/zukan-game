## 1. 新しい仕組み①：倒れるほど軽くなるコスト

### やること
キャラに `costRule` を書けるようにする。

```js
costRule: { type: 'perDeath', amount: 1, min: 3 }
```

- **実効コスト ＝ max(min, cost − amount × そのバトルで倒れたカードの総数)**
- 倒れたカードは**敵味方どちらも数える**（呼び出されたトークンも含む）
- カウントはバトルごと。`Battle` に「これまでに倒れた数」を持たせ、`resolveDeaths` で増やす

### 触るところ
- `Battle`：カウンタの追加、実効コストを返す関数（例：`costOf(card)`）
- 手札からカードを出す判定（`deploy` の `o.c.cost <= pl.energy`）と、エナジーの支払いを実効コストにする
- `compileCard` の攻撃・体力の自動計算は、**基本コストのまま**（軽くなる分は強みとして残す）

### 画面
- デッキ編集のカード詳細に「場のカードが1体倒れるごとにコスト−1（最低3）」と表示する
- バトル中は表示を変えなくてよい（ログに出す必要もない）

## 2. 新しい仕組み②：きっかけ「敵味方問わず、カードが倒れた時」

### やること
固有能力のきっかけに `anyDeath` を追加する。

- `TRIGGERS.anyDeath = { text: '敵味方のカードが倒れた時', w: 1.6 }`
- `resolveDeaths` で、倒れた1体につき、**生き残っている全カード**の `anyDeath` を発火する
- 自分自身が倒れた場合は発火しない（`death` の役目）
- 設置型アーティファクト（relic）でも同じきっかけを使えるようにする
- 連鎖で無限に発火しないよう、既存の `resolveDeaths` の繰り返し上限を守る

`w`（点数の重み）は仮の値。3の調整で勝率を見て決めてよい。

## 3. 新しい仕組み③：キャラ固有の奥義（ROADMAP B-5）

### やること
キャラに `ultimate` を書けるようにする。書いてあれば、属性共通の奥義の代わりに使う。

```js
ultimate: { name: '神装戦域・開帝', effects: [ ... ] }
```

- 効果は**複数指定できる**ようにする（`applyEffect` を順番に適用）
- 発動条件は今と同じ（★5の個体をデッキに入れていると、登場時に1回だけ）
- カード詳細の「奥義」欄には、固有のものがあればそちらを表示する
- 既存キャラは `ultimate` を書かないので、これまでどおり属性共通の奥義のまま

## 4. キャラの追加

`data/characters.js` の末尾に、次を追加する（数値は案。5の条件を満たさなければ調整してよい）。

```js
{
  id: 'chr_031', name: 'マッチ＝ヴァルガルド', category: '戦争の化身（マッチ神）',
  story: true, art: { base: 1, r4: 0, r5: 0 }, hue: 20, shape: 2,
  base_weight: 900, base_height: 360,
  speed_bias: 200, wisdom_bias: 600, luck_bias: 400, appetite_bias: 800,
  likely_natures: ['負けず嫌い', 'ゆうかん', 'いじっぱり'],
  element: '土', tribes: ['マッチ神', '戦争'], cost: 9, ratio: 0.55,
  keywords: ['貫通', '反撃'], skill: '神装戦域',
  ability: { trigger: 'anyDeath', effect: { type: 'buff', target: 'self', atk: 1, hp: 1 } },
  costRule: { type: 'perDeath', amount: 1, min: 3 },
  ultimate: { name: '神装戦域・開帝', effects: [
    { type: 'damage', target: 'allEnemies', amount: 2 },
    { type: 'buff', target: 'self', atk: 3, hp: 3 }
  ] }
}
```

### 設定とのつながり（変えるときの参考）

| 設定 | ゲームでの表現 |
|---|---|
| 攻撃力9・防御力9の大型 | 高コスト・高い攻撃と体力、貫通と反撃 |
| 素早さ3 | `speed_bias` を低く（土属性なので速さも最下位） |
| 戦いが激しくなるほど強くなる | 固有能力「神装戦域」＝敵味方が倒れるたび攻撃+1・体力+1 |
| 争いが激化するほど戦場に現れやすい | コストが倒れた数だけ軽くなる |
| 正面から叩き潰す | 貫通（余ったダメージが後ろへ）／反撃 |
