# Codexへの依頼の書き方

短くても、次の4つがあれば作業できる。

```
【やりたいこと】
【理由・背景】
【完了の条件】
【変えてほしくないもの】
```

## 例1：キャラを追加する

```
【やりたいこと】
No.031 に新しいキャラ「○○」を追加する。

【素材】
- 画像：img/chr_031_base_1.webp と chr_031_base_1_s.webp（アップロード済み）
- 図鑑の文章：下に貼る★1〜★5の文章をそのまま使う
- 種族：ネットミーム / ミーム生命
- 戦い方のイメージ：仲間が倒れるほど強くなる

【完了の条件】
- data/characters.js の末尾にキャラを追加（id は chr_031、art は base:1）
- stories/chr_031.js を作る
- 属性・コスト・キーワード・固有能力は、戦い方のイメージに合うものを提案する
- node tools/sim.js battles 4000 を実行し、このカードの勝率が46〜54%に収まることを確認する
- 収まらない場合はコストか能力を調整し、その理由を説明に書く

【変えてほしくないもの】
既存キャラの数値、クエスト、ルール
```

## 例2：数値を調整する

```
【やりたいこと】
クエスト「霧の森の奥へ」と「台所の大宴会」が簡単すぎるので難しくする。

【完了の条件】
- node tools/sim.js quests の勝率が、どちらも5〜6割になる
- 敵のリーダー体力・デッキ・特殊ルールのどれで調整したかを説明に書く
- 変更前後の数値を並べて書く

【変えてほしくないもの】
プレイヤー側のルール（デッキ枚数、リーダー体力など）、他のクエスト
```

## 例3：機能を追加する

```
【やりたいこと】
ピックアップガチャ（docs/ROADMAP.md の B-1）を作る。

【完了の条件】
- ガチャ画面で「通常」と「ピックアップ」を選べる
- ピックアップ中のキャラは出る確率が3倍。確率表示にも反映される
- 対象キャラと期間は data/rules.js の1か所で設定できる
- 抽選は GameServer の中だけで行う（画面側に判定を書かない）
- 既存の保存データで開いてもエラーが出ない

【変えてほしくないもの】
既存のガチャの確率、コインの値段
```

## 作業後に作者が確認すること

Codexの説明に、次を書いてもらう。

1. 変えたファイル
2. `node tools/sim.js` の結果（数値を変えた場合は変更前後）
3. スマホのどの画面を見れば確認できるか
4. 保存データへの影響の有無
