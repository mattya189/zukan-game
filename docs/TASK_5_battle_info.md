# 依頼5：戦闘時の効果の欄と、戦闘の説明を追加する

依頼4（集団戦）まで終わっている前提。**文章はすべて用意済み**で、Codexは表示する場所を作るだけ。

## 0. 用意してあるファイル（アップロード済み）

| ファイル | 中身 |
|---|---|
| `data/battle-effects.js` | キャラ10体の「戦闘時の効果」（`BATTLE_EFFECTS`）と、集団戦だけの効果（`TEAM_EFFECTS`） |
| `data/help-battle.js` | 戦闘の説明（`HELP_BATTLE`。11の見出しと本文） |

読み込み順は、`data/characters.js` のあと、`js/game.js` より前ならどこでもよい。

## 1. 図鑑に「戦闘時の効果」の欄を足す

図鑑のキャラページの「**戦闘能力**」タブに、次の順で表示する。

1. 戦闘タイプ（今あるもの）
2. 能力値6つの棒グラフ（今あるもの）
3. 覚悟・性質タグ（今あるもの）
4. **【新しく足す】戦闘時の効果**
5. 設定の文章（`combat/` のまとまり。今あるもの）

### 新しい欄の中身

```js
const e = BATTLE_EFFECTS[charId];
e.role            // ひとこと（例：長引くほど強くなる重装甲。逃げる相手を鎖で捕まえて殴る）
e.effects         // [[技の名前, 効果の説明], ...]
TEAM_EFFECTS[charId]  // 集団戦だけの効果。同じ形。空の場合もある
```

- 一番上に `role` を1行（少し大きめ、または枠で囲う）
- その下に `effects` を並べる。**技の名前は太字**、説明はその下か右に。行ごとに区切り線
- 「弱点」の行は、ほかと色を変えて目立たせる（赤系など）
- `TEAM_EFFECTS` があれば、「**集団戦での効果**」という小見出しを付けて続ける。空の配列なら、その小見出しごと出さない
- 設定の文章（4の下）との違いが分かるよう、この欄には「ゲームでの動き」といった小見出しを付ける

文章が長いので、**このまとまりもたためる形**にしてよい（初期は開いた状態）。

## 2. 戦闘の説明のページを足す

`HELP_BATTLE` は `[{ title, body }, ...]` の配列。`body` は改行を含む文章なので、**改行をそのまま表示**する（`white-space: pre-line` など）。

### 置き場所
次の3か所から開けるようにする。
- 設定画面の「戦闘について」
- 対戦（練習試合）の画面
- クエストの挑戦前の画面

開き方は、ゲームの他の説明と同じ形（小窓でも、1ページでもよい）。見出しごとにたためる形が読みやすい。

## 3. 完了の条件

1. 図鑑の10体すべてで「戦闘時の効果」が表示され、技の名前と説明、弱点、集団戦での効果（ある場合）が出る
2. 戦闘の説明が、設定・対戦・クエストの3か所から開ける
3. 説明の改行がそのまま表示される
4. 幅360〜430pxのスマホ縦画面で崩れない
5. `node --check` が `js/game.js`・`data/battle-effects.js`・`data/help-battle.js` で通る
6. 既存の保存データで開いてもエラーが出ない

## 4. 変えてほしくないもの

- `data/battle-effects.js` と `data/help-battle.js` の文章（表示の形は変えてよい）
- 戦闘の計算（`js/battle.js`・`js/team.js`）とキャラのデータ
- 図鑑のほかのタブ

## 5. 注意

この2つのファイルは、**戦闘の計算に合わせて書いた説明文**です。今後 `js/battle.js` や `js/team.js` の数値を変えたときは、この文章も合わせて直す必要があります（作業者への申し送りとして、ファイルの先頭にも書いてあります）。
