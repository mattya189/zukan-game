# 依頼7：はじめての案内（チュートリアル）を付ける

新しく始めた人に、**最初の一周だけ**を案内する。文章は用意済み。

## 0. 用意してあるファイル（アップロード済み）

| ファイル | 中身 |
|---|---|
| `data/tutorial.js` | 案内の文章6ステップ（`TUTORIAL_STEPS`）と報酬（`TUTORIAL_REWARD` ＝ 100コイン） |

読み込み順は、`js/game.js` より前ならどこでもよい。

## 1. 動き

- **初回だけ自動で始まる**（保存データに案内の記録がない人）
- 画面の下の方に、**案内の帯**を出す。中身は `title`（太字1行）と `body`（1〜2文）
- 帯には「あとで見る」ボタン。押すと案内をしまい、設定から再開できる
- そのステップの `tab` に切り替えるよう促し、`target` の場所を光らせる（枠を点滅させる、または矢印を出す）。`target` は画面側で場所を決めてよい。難しければ、光らせる演出は省いて文章だけでもよい
- `done` の出来事が起きたら、**自動で次のステップへ**進む
- 最後の `finish` を閉じると、**報酬100コイン**を1度だけ渡し、「案内おつかれさま。100コイン（ガチャ1回分）を受け取りました」と伝える
- 案内中でも、ほかの画面は普通に操作できる（進行を妨げない）

### 進む条件（`done`）
| ステップ | 条件 |
|---|---|
| gacha | ガチャを1回引く（1回引き・10回引きどちらでも） |
| individual | 個体票を開く |
| zukan | 図鑑のキャラページを開く |
| quest | キャラ別の試練にどれか1回**挑戦する**（勝ち負けは問わない） |
| farm | 周回ステージにどれか1回**挑戦する**（勝ち負けは問わない） |
| finish | 案内を閉じる |

すでに条件を満たしている人（途中から始めた人）は、そのステップを飛ばす。

### 負けが続いたときの案内（`retry`）

`quest` と `farm` のステップには `retry` が入っている。**そのステップの間に負けた回数**を数え、`after` の回数に達したら、帯の `title` と `body` をその文章に差し替える。

| ステップ | 2連敗したら | 3連敗したら |
|---|---|---|
| quest | 「勝てないときは、個体を変えてみよう」（ヒントと絞り込みの案内） | 「別のキャラの試練でもいい」 |
| farm | 「初級から挑戦してみよう」 | ― |

- 勝ったら負けの回数は0に戻す
- 挑戦した時点で次のステップへ進むので、`retry` は**同じステップに留まっている間だけ**出る（挑戦して負けた直後に次へ進む場合は、次の挑戦から出る形でよい）
- 負けの回数は保存しなくてよい（アプリを開き直したら0でよい）

## 2. 保存データ

`tutorial = { step: 0, done: false, rewarded: false, hidden: false }` を保存する。
- `step` … 今のステップの番号
- `done` … 最後まで終わったか
- `rewarded` … 報酬を渡したか（**2回渡さない**）
- `hidden` … 「あとで見る」でしまっているか

古い保存データには無いので、読み込み時に補う。**すでに遊んでいる人には、案内を自動で出さない**（`done: true` として扱う）。報酬も渡さない。

## 3. 設定画面

「はじめての案内をもう一度見る」を置く。押すと最初のステップから再開する。
**やり直しても報酬は渡さない**（`rewarded` を見る）。

## 4. 完了の条件

1. データを消して始めると、案内が自動で出て、6ステップが順に進む
2. 各ステップは、対応する操作をすると自動で次へ進む
3. 「あとで見る」でしまえて、設定から再開できる
4. 最後まで終わると100コインが1度だけ入る。やり直しても増えない
5. すでに遊んでいる保存データでは、案内が自動で出ない
6. 案内中でも、ほかの操作ができる
7. 幅360〜430pxのスマホ縦画面で、案内の帯が操作の邪魔にならない
8. `node --check` が `js/game.js` と `data/tutorial.js` で通る

## 5. 変えてほしくないもの

- `data/tutorial.js` の文章（表示の形は変えてよい）
- ゲームのルール、報酬の額（100コインのみ）
