# 依頼9：個体の数値をひと目で見えるようにする（保管庫・送り出し・個体選び）

保管庫で送り出すときや、バトルで個体を選ぶときに、**パワー・すばやさ・かしこさがその場で見える**ようにし、
**その数値で並べ替え・絞り込みができる**ようにする。新しいデータは要らない（すでに個体が持っている値を使う）。

## 1. 個体の行に、数値を出す

保管庫・送り出し・バトルの個体選び（クエスト／練習試合／集団戦の編成）で使う**共通の行**を作り、次を表示する。

```
[絵] ヴァルガルド ★★★★         パワー 1,236
     #000087 いじっぱり 4.2kg    速さ 412 ／ 賢さ 187
     [怪力] [韋駄天]
```

- **1行目**：名前、★、いま並べ替えに使っている項目の値（大きめ・右寄せ）
- **2行目**：通し番号、性格、体重、そして**パワー・すばやさ・かしこさ**（小さめ。並べ替えに使っている項目は太字）
- **3行目**：称号（あれば）。特異個体の印もここ
- 幅が狭い画面では、2行目を「P 1,236／速 412／賢 187」のように省略してよい（数字は必ず見えるようにする）
- 数値は3桁ごとに区切る（1,236）

## 2. 並べ替えを増やす

今の並べ替えに、次を足す（すべて「高い順／低い順」を選べる）。

| 並べ替え |
|---|
| 新しい順（今のまま） |
| パワー |
| すばやさ |
| かしこさ |
| 体重／身長 |
| うんのよさ／かがやき／食欲／性格の強さ |
| 総合値 |
| 称号の数 |

**バトルの個体選びでも、この並べ替えを使えるようにする**（今は保管庫にしかない）。

## 3. 絞り込みを増やす

依頼6で入れた「戦い方」の絞り込みに加えて、次を足す。

- **称号つきだけ**（今もある場合は残す）
- **特異個体だけ**
- **数値のしきい値**：「パワー1,000以上」「すばやさ1,000以上」「かしこさ1,000以上」をボタンで選べる（複数選んだときは「すべてに当てはまる」）

## 4. 送り出しの画面

- 送り出す個体を選ぶ一覧でも、上の行と並べ替え・絞り込みをそのまま使う
- 選んだ個体の**合計のコイン**を、確定ボタンの近くに常に表示する
- **誤って強い個体を送り出さないように**、次のどちらかに当てはまる個体を選ぶと、行に警告の色を付け、確定前に「この個体を送り出しますか」と確認する
  - 称号が2つ以上ついている
  - パワー・すばやさ・かしこさのいずれかが1,000以上
  - 特異個体
- 「まとめて選ぶ」ボタンがある場合は、上の条件に当てはまる個体を**最初から外して**選ぶ

## 5. 完了の条件

1. 保管庫・送り出し・バトルの個体選びで、パワー・すばやさ・かしこさが常に見える
2. どの画面でも、パワーなどで並べ替えられる（高い順・低い順）
3. しきい値の絞り込み（1,000以上）と、称号つき・特異個体の絞り込みが動く
4. 送り出しで、強い個体を選ぶと警告が出て、確認をはさむ
5. 選んだ個体の合計コインが常に見える
6. 幅360〜430pxのスマホ縦画面で、行が崩れず、数字が読める
7. `node --check js/game.js` が通る
8. 既存の保存データで開いてもエラーが出ない

## 6. 変えてほしくないもの

- 個体値の仕組みと、送り出しでもらえるコインの額
- 依頼6で入れた戦い方の絞り込み（残したうえで、数値の絞り込みを足す）
- 戦闘の計算
